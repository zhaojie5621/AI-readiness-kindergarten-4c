# Contributing

This repository supports a specific research manuscript. Contributions should preserve methodological traceability and numerical consistency.

## Contribution principles

- Do not add respondent-level data unless redistribution permission is documented.
- Do not change verified manuscript values without evidence and author approval.
- Keep AIRPAC-Q and Vietnam respondent-level analyses independent.
- Do not introduce respondent-level pooling.
- Use observed-variable path analysis terminology for the Vietnam model.
- Add or update tests and documentation when analytical code changes.
- Record substantive changes in `CHANGELOG.md`.

## Suggested workflow

1. Create a branch.
2. Make a focused change.
3. Run the notebooks or validation workflow.
4. Confirm that affected manuscript outputs remain correct.
5. Open a pull request describing the methodological and numerical impact.

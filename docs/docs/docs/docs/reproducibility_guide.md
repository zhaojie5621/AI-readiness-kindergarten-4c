Reproducibility Guide
Objective
This repository enables independent reproduction of the analytical workflow used in the associated manuscript.
Recommended execution order
Install Python packages.
Create the Conda environment (optional).
Prepare the input datasets according to `data/README.md`.
Execute notebooks in numerical order.
Compare generated outputs with the manuscript tables and figures.
Workflow
Input Data
→ Data preprocessing
→ Reliability analysis
→ CFA / Path modeling
→ Machine learning
→ Profile analysis
→ Evidence synthesis
→ Tables
→ Figures
→ Manuscript
Reproducibility principles
Fixed random seeds
Version-controlled code
Non-identifying outputs
Documented software versions
Transparent analytical decisions

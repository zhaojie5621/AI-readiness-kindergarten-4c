# Analysis Decisions

## Key methodological decisions

- Respondent-level datasets are analyzed independently.
- No pooled respondent-level dataset is created.
- Cross-dataset measurement invariance is not assumed.
- Cross-study integration is performed at the construct, effect, profile, and evidence levels.
- AIRPAC-Q is analyzed using confirmatory factor analysis, structural equation modeling, bootstrap mediation, profile analysis, and machine learning.
- Vietnam ECE is analyzed using observed-variable path analysis, profile analysis, and machine learning.
- Machine learning is used for predictive validation and variable-importance assessment, not causal inference.
- Cross-source profile mappings are interpreted as conceptual analogies rather than statistically equivalent latent classes.
- The professional-development priority index is exploratory.

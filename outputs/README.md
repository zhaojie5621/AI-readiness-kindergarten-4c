# Outputs

This directory stores reproducible, non-identifying analytical outputs.

## Subdirectories

- `tables/` — machine-readable main-manuscript tables;
- `figures/` — final generated figures;
- `excel/` — consolidated workbooks;
- `diagnostics/` — model-fit, cross-validation, and sensitivity outputs.

Only outputs verified against the final manuscript and Supplementary Material should be marked as final.

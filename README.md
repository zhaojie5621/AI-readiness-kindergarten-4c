# Data Availability and Placement

## Purpose

This directory documents the datasets required to reproduce the analyses while respecting licensing, consent, privacy, and redistribution restrictions.

## Expected local structure

```text
data/
├── README.md
├── codebooks/
├── templates/
├── processed/
└── raw/              # local only; excluded by .gitignore
```

## AIRPAC-Q

The AIRPAC-Q analytical file should be stored locally only when redistribution rights are uncertain. The final repository will provide the verified source, expected filename, variable map, and checksum where legally permissible.

## Vietnam ECE

The respondent-level Vietnam file must not be uploaded publicly unless redistribution permission is confirmed. Publicly shared materials should be limited to non-identifying codebooks, templates, aggregate outputs, and reproducible scripts.

## Direct Chinese evidence

The structured evidence register may be shared if it contains bibliographic and extracted study-level information only and does not reproduce copyrighted full text.

## Privacy safeguards

Do not upload names, email addresses, institutional identifiers, free-text responses containing personal information, credentials, or direct identifiers.

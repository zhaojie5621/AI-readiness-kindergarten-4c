# Data and Input Templates

This package contains blank or illustrative templates only. It does not contain respondent-level data.

## Included files

- `data/codebooks/airpac_codebook_template.csv`
- `data/codebooks/vietnam_codebook_template.csv`
- `data/templates/expected_files_template.csv`
- `inputs/china_evidence_register/china_evidence_register_template.xlsx`
- `inputs/construct_crosswalk/construct_crosswalk_template.xlsx`

Before version 1.0.0, all variable names, coding directions, item mappings, and study-level entries must be checked against the verified analytical files and final Supplementary Material.
